# 1. Install the packages into the SAME Python that Webots uses to run the
#    controller (Webots: Tools > Preferences > General > Python command):
#        python -m pip install --upgrade pip
#        python -m pip install -r requirements.txt
#
# 2. Download the model file into the models/ folder. No account or login is
#    needed. Either open the Download link above in a browser and save the file
#    as models/qwen2.5-3b-instruct-q4_k_m.gguf, or run:
#        curl -L -o models/qwen2.5-3b-instruct-q4_k_m.gguf https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q4_k_m.gguf
#    The file name must match exactly: config/llm_config.json already points
#    to models/qwen2.5-3b-instruct-q4_k_m.gguf, so nothing needs editing.
#
# 3. Check that the planner works without Webots:
#        python -m unittest discover -s tests -v
#    (the 4 real-model tests are skipped if the model file or llama-cpp-python
#    is missing; with both installed they run and should pass)
#        python evaluation/run_planner_eval.py
#    (plans 12 test goals with the real model, prints each plan and a summary,
#    and saves the results in evaluation/results/)
#
# 4. Run the robot: open worlds/project_genai_embodied_assistant.wbt in Webots
#    and start the simulation. The model loads on the first planning request
#    in a worker thread, so the first plan takes longer than later ones
#    (expect about 30-60 s per plan on a laptop CPU).
